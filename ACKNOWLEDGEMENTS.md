# Acknowledgements

Trayce was developed as an individual project for the NUS CS2103T Software Engineering course.

The repository scaffolding, Gradle configuration, and JavaFX chat-interface structure were adapted
from the CS2103T individual-project template and Duke project materials provided by the course.
Those materials include the launcher, FXML-based main window, and dialog-box approach that this
project subsequently customized for Trayce.

- [CS2103T individual project documentation](https://nus-cs2103-ay2627s1.github.io/website/schedule/week10/project.html)
- [SE-EDU JavaFX tutorial](https://se-education.org/guides/tutorials/javaFx.html)

All Trayce-specific task behavior, storage format, validation, tests, wording, and visual styling in
this repository were implemented and customized for this project.
